# ORRW-Lower-Bound

Lean 4 proofs accompanying **Once-reinforced random walk on `ℤ^d` has range
exponent at least `d/(d+1)`**, by Ahmed Bou-Rabee and Yuval Peres.

For every dimension `d ≥ 2` and reinforcement `β ≥ 1`, the expected number of
sites visited in `n` steps is at least `c(d) (n/β)^{d/(d+1)}`, where `c(d) > 0`.
The development also proves a range lower-tail bound, occupation estimates,
and almost-sure lower bounds on range and maximal displacement.

## Building and checking

Install [elan](https://github.com/leanprover/elan), Python 3.10 or newer, and
PyYAML. The Lean version and Mathlib revision are pinned in `lean-toolchain`
and `lake-manifest.json`.

```sh
python3 -m pip install -r tools/requirements.txt
lake exe cache get
python3 tools/verify.py
```

`verify.py` builds the library, audits every frozen export, checks the paper
and statement hashes, and checks the generated documentation and certificate.
It also runs regression tests for the verification scripts. Any failure returns
a nonzero exit status. GitHub Actions runs the same command.

To inspect the exported statements' axiom dependencies directly:

```sh
lake env lean ORRW/Certificate.lean
```

After an intentional update, regenerate the certificate with
`python3 tools/certificate.py`. It is written only after its checks succeed.
A failed Lean command, missing axiom output, or an axiom outside `propext`,
`Classical.choice`, and `Quot.sound` fails the audit.

Each declaration in `ORRW/Frozen/` has a statement whose bytes are pinned in
`ledger/manifest.yaml`. These hashes detect statement changes. The coverage
check detects missing paper labels. The clause, exponent, and constant checks
are text-based aids to review; none proves equivalence between LaTeX and Lean.
The notes in VERIFICATION.md are part of the mathematical review.

## Building the paper

The snapshot includes its bibliography and both figures. With pdfLaTeX and
BibTeX installed:

```sh
cd paper
pdflatex -interaction=nonstopmode -halt-on-error orrw.tex
bibtex orrw
pdflatex -interaction=nonstopmode -halt-on-error orrw.tex
pdflatex -interaction=nonstopmode -halt-on-error orrw.tex
```

The snapshot compiles to 15 pages. The survey, simulations, figures, and open
questions are outside the formalization.
