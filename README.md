# ORRW-Lower-Bound

A Lean 4 formalization of

> **Once-reinforced random walk on `ℤ^d` has range exponent at least `d/(d+1)`**
> Ahmed Bou-Rabee and Yuval Peres

Every theorem, lemma and proposition of the paper is stated here and proved from
Mathlib alone.  `CERTIFICATE.md` records what a machine has checked, and how to
check it again; it is generated, not written.

## The model

Once-reinforced random walk on `ℤ^d`.  Every edge starts with weight `1`; once
the walk has crossed an edge, that edge has weight `β ≥ 1` forever after.  Each
step chooses an edge incident to the current site with probability proportional
to its weight.  `R_n` is the set of sites visited in the first `n` steps.  The
main theorem is that `𝔼_β|R_n| ≥ c (n/β)^{d/(d+1)}`.

## How a statement is tied to the paper

Each theorem in `ORRW/Frozen/` sits between `-- FROZEN-STATEMENT-BEGIN` and
`-- FROZEN-STATEMENT-END`.  Those bytes are the contract: `ledger/manifest.yaml`
records their SHA-256 and the paper `\label` they transcribe, so a statement
cannot be quietly weakened after it is proved.  The proof follows the end
marker and may be rewritten freely.

The correspondence is not left to the reader's trust.  Each statement has been
read against the paper clause by clause and the reading recorded; run
`python3 tools/check_clauses.py` to see it.

## Building and checking

The checks require Python 3 with PyYAML.  The Lean toolchain and Mathlib
revision are pinned in `lean-toolchain` and `lake-manifest.json`.

```
elan toolchain install $(cat lean-toolchain)
lake exe cache get      # optional: prebuilt Mathlib
lake build ORRW
```

Ten checks, all of which must pass:

| command | what it guarantees |
|---|---|
| `python3 tools/check_manifest.py` | every frozen statement still hashes to its manifest entry, so none has been altered since it was proved |
| `python3 tools/check_axioms.py` | no proof's axiom closure contains `sorryAx`; the only axioms used are Lean's three classical ones |
| `python3 tools/check_warnings.py` | the build emits no warning the manifest does not authorize |
| `python3 tools/check_coverage.py` | every theorem, lemma and proposition in the paper is claimed by a node |
| `python3 tools/check_clauses.py` | every paper statement has a recorded, clause-by-clause correspondence with its Lean statement |
| `python3 tools/check_constants.py` | no constant is bound after `β` or `n`, so every constant depends only on the dimension |
| `python3 tools/check_exponents.py` | every exponent in a paper statement appears in its Lean statement |
| `python3 tools/paper_anchors.py` | every paper line range in the manifest still spans the `\label` it names |
| `python3 tools/paper_citations.py` | every paper citation in the sources still points where it says |
| `python3 tools/sync_docs.py` | `README.md` and `CORRESPONDENCE.md` agree with the manifest |

`python3 tools/certificate.py --check` verifies that `CERTIFICATE.md` describes
the tree as it currently stands.

## Scope

Formalized: every theorem, lemma and proposition of the paper, together with the
two almost-sure corollaries it states in prose, which are proved against a
measure on infinite paths built here from the walk's one-step kernels.

The open questions of Section 9, the figures and simulations, and the survey in
Section 1.3 are outside the formalization.  Effective resistance is *defined*
by the Schur identity rather than constructed from an electrical network.
The exponential-moment bound in Lemma 5.1 is stated and formalized for the
ORRW filtration, with adapted processes Phi and Gamma and a stopping time.  Its bounds
hold at every finite horizon and suffice for its application to the walk.
`CORRESPONDENCE.md` records the modelling decisions.

## Building the paper

The `paper/` directory includes the bibliography and both figures.  With
pdfLaTeX and BibTeX installed, run:

```sh
cd paper
pdflatex -interaction=nonstopmode -halt-on-error orrw.tex
bibtex orrw
pdflatex -interaction=nonstopmode -halt-on-error orrw.tex
pdflatex -interaction=nonstopmode -halt-on-error orrw.tex
```

The revised paper has 17 pages.  `checks/FindingsAudit.lean` records the
kernel-checked examples used to review the corrected proof prose.  Run it after
building the library:

```sh
lake env lean checks/FindingsAudit.lean
```
